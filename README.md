##  Proyecto Destacado

###  AgroConecta
> Plataforma de e-commerce agrícola full-stack

-  **Frontend:** Angular con dashboards interactivos y ApexCharts
-  **Backend:** Laravel REST API con autenticación OAuth
-  **Pagos:** Integración con PayPal y múltiples métodos de pago
-  **Chat:** Sistema de mensajería en tiempo real
-  **Despliegue:** Azure + Docker + Azure Blob Storage
